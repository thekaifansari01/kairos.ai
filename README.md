kairos AI – An elite cybersecurity-focused coding assistant with real-time Python execution, project-aware RAG, and multi-model intelligence.

Tech Stack: Vanilla JS (ES2020), Pyodide, Transformers.js, IndexedDB, Firebase (Auth + Firestore), Groq, OpenRouter, Gemini API, Web Speech API, Service Workers.

🔥 What Makes It Special:

Live Python Interpreter – Run code blocks inside chat via Pyodide Web Worker. Supports abort, timeout, and standard libraries. Output appears inline.

Project-Aware RAG – Drag-drop any folder. Code is token-aware chunked, embedded with MiniLM (Xenova/all-MiniLM-L6-v2), stored in IndexedDB. Chat automatically retrieves relevant snippets from your actual codebase.

Multi-Model Hub – Switch seamlessly between Llama 3.3, Gemini 2.5 Flash, Qwen, Nemotron, GPT-OSS, Kimi-K2 – all free tiers.

Cybersecurity Lens – Built-in security audit prompts and vulnerability awareness for code review.

Cloud Sync – Google login saves conversations to Firestore. Pinned messages, searchable history, accessible across devices.

Smart UX – / triggers template dropdown (keyboard nav), attach text files to prompts, copy/edit/regenerate messages, TTS, export as .txt/.json.

Modular & Offline-Ready – No heavy frameworks. Service Worker caches assets. Custom modal system replaces native prompts.

Impact: Complete AI workspace for developers who ship fast and think secure. Zero setup – runs entirely in browser.
